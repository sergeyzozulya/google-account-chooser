Google Account Chooser (and Dashboard)

Automatically routes Google service links through Account Chooser so you can pick the right Google account before the page loads — no more accidentally opening Gmail or Drive in the wrong account. About & Privacy

Gmail

Expand unread emails
Where each account lists its unread inbox mail right away; the unread badge folds and unfolds the list. Elsewhere the badge opens the list. Popup includes the side panel.
Emails listed
How many unread emails each account lists, newest first. Gmail's feed has at most 20.
Text lines
Lines of each email's text under its subject; with none, just the sender and subject.
Sender avatars
Show a letter avatar for each sender in email lists and threads.
List header
Show “Inbox” and Open Gmail above the email list in each account card.
Clicking an email
Show its thread in the list, or open it in Gmail. Ctrl/⌘-click always opens it in Gmail.
Thread messages
Which messages of a thread are open when it shows; click a message's header to open or fold it.
Check mail every
How often unread counts and emails are refreshed, on the dashboard and on the toolbar icon.
Toolbar icon count
Unread count on the extension's toolbar icon.

Open tabs

Tabs
Which open tabs to list. Grouped by account, tabs of other sites go under Other tabs.
Grouping
List tabs under each browser window and installed web app (with just one window, in a single list), under each account, or in one list in window order. Unless grouped by account, each tab shows its account's avatar.
Close buttons
Show × on a tab's row when you point at it, to close the tab from the list (on the dashboard and in the popup).
Tab groups
Mark tabs in a Chrome tab group with a strip of the group's color; point at a tab to see the group's name.

Recent files

Files listed
How many files each group lists (each account or type), or the whole list when not grouped.
Grouping
List files under each account, under each type (Docs, Sheets, Slides, Forms), or in one list. Unless grouped by account, each file shows its account's avatar.
File types
Which kinds of files to list.
Period
List files opened within this time. Chrome keeps about 90 days of history.
Sort
Most visited counts every visit to a file in your browser history.

Window

Placement
Center — the window appears centered on your screen. Tiles — each window cascades offset from the previous one. Custom — remembers the position you last moved each service window to.
Size
Default — 1024×768. Large — 75% of the current window. Full screen — matches the current window size. Custom — starts at 1024×768 and remembers the size you resize each service window to.
